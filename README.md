# UTME ATTACK FORCE AI

An AI study assistant for UTME/JAMB students.

## Subjects

- English Language
- Mathematics
- Chemistry
- Physics
- Biology

## Features

- Answer UTME questions
- Explain difficult topics
- Generate practice questions
- Give corrections and explanations
- Help students prepare for JAMB

## WhatsApp AI

UTME ATTACK FORCE AI will eventually be connected to WhatsApp so students can interact with the AI directly.

## Goal

To build a powerful and accessible AI study assistant for Nigerian students.
